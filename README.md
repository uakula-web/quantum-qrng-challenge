# ⚛️ IBM Qiskit Quantum Random Number Generator (QRNG)

An advanced quantum computing application engineered with Python and the IBM Qiskit SDK to construct, simulate, and benchmark an unbiased 4-qubit Quantum Random Number Generator (QRNG) against classical pseudorandom software logic architectures.

## 🛠️ Architecture Stack
- **Quantum Core SDK:** IBM Qiskit (Superposition gate vector design)
- **Simulation Layer:** Qiskit Aer high-performance local processing simulator
- **Mathematical Validation:** NumPy statistical data matrix handling

## 📊 Evaluation & Verification Metrics
This engine uses zero confidential or synthetic mock data structures. It functions completely on live operational variables generated by putting qubits through localized Hadamard (H) gate transformations:
- **Quantum State Space Matrix:** 4 active nodes (qubits), operating securely under standard testing limits.
- **Bit Balance Test:** Evaluates the statistical occurrence balance of binary outputs aiming for an unbiased 0.50 execution probability scale.
- **Classical Benchmark:** Runs a side-by-side performance track comparing true quantum randomness stability against CPU pseudorandom methods.
